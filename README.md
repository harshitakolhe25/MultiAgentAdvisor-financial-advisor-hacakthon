# MultiAgentAdvisor-financial-advisor-hacakthon
# 💎 FinVerse AI – Multi-Agent Financial Advisory Simulator

An AI-powered **Multi-Agent Financial Advisory Simulator** that brings together specialized AI advisors to collaboratively analyze financial situations and generate transparent, educational, and well-reasoned financial recommendations.

Developed as a Promptathon project to demonstrate the power of **Multi-Agent AI Systems**, **Explainable AI**, and **Intelligent Financial Decision Support**.

---

# 🚀 Overview

FinVerse AI is a next-generation financial intelligence platform that simulates collaboration between multiple AI financial advisors instead of relying on a single AI response.

Each AI advisor specializes in a different financial domain, independently analyzes the user's financial profile, and contributes its expertise before a final consensus recommendation is generated.

The platform emphasizes:

- Multi-Agent Collaboration
- Explainable AI
- Educational Financial Guidance
- Transparent Decision Making
- Responsible AI

---

# 🎯 Problem Statement

Traditional AI assistants usually generate responses from a single model, often overlooking multiple financial perspectives.

FinVerse AI addresses this challenge by introducing a **Multi-Agent Financial Advisory Simulator**, where specialized AI advisors collaborate to analyze budgeting, risk, investments, taxation, retirement planning, insurance, market conditions, and behavioral finance before generating a balanced recommendation.

# ⚙ Installation

Clone the repository

```bash
git clone https://github.com/<your-github-username>/FinVerse-AI.git
```

Navigate to the project

```bash
cd FinVerse-AI
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

---

# 🔑 Environment Variables

Create a `.env.local` file.

```env
NEXT_PUBLIC_FIREBASE_API_KEY=

NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=

NEXT_PUBLIC_FIREBASE_PROJECT_ID=

NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=

NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=

NEXT_PUBLIC_FIREBASE_APP_ID=

NEXT_PUBLIC_GEMINI_API_KEY=
```

---

# ☁ Firebase Setup

1. Create a Firebase project.
2. Enable Authentication.
3. Enable Google Sign-In.
4. Enable Cloud Firestore.
5. Copy your Firebase configuration into `.env.local`.

---

# 🤖 Gemini API Setup

1. Generate a Gemini API Key.
2. Add the key to `.env.local`.
3. Restart the development server.
